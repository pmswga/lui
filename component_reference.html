Lui translator commands

To work with lui.exe you need to download it and add it to PATH. At the moment lui.exe supports the following commands.

Command Description
--help View all commands
--file=[filename] Set the *.lui file for generation
--debug Turn on debug mode. View debug information at each step of translation.
--version View the current version of Lui

Lui #defines

Lui defines are constants that allow the Lui preprocessor to understand where user code and other things are.

Define Description
#LUI Separate user code and Lui code
#FILENAME ["filename"] Set the name of the resulting Python file

1 Forms

Components allow you to create forms such as basic windows, dialogs or messages.

1.1 Window

It's the main component of any GUI. 

Window {
	title: "Window caption"
	width: 640
	height: 640
}
Property Description
title Set the title of the window
width Set the width of the window
height Set the height of the window
background-color Set the background-color of the window

3 Input

Groups of widgets allow users to input data.

3.1 Button

It's a basic button. 

Button {
	caption: "Button caption"
}
Property Description
caption Set the text caption of the button

4 Output

Groups of widgets allow you to output information from your variables.

4.1 Label

It's a simple label. 

Label {
	caption: "Label caption"
}
Property Description
caption Set the text caption of the label

4.2 List

It's a list widget. With a list you can output your variables, such as a list or a tuple. 

List {
	data: my_lst
}
Property Description
data Set any list for output
