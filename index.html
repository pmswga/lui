What is Lui?

Lui is a specialized programming language for the declarative description of user interfaces with automatic generation of Tkinter (Python) code. Describe your UI in a simple and understandable format, and Lui will create ready-to-run Python code for you.

Key features:

  • Declarative syntax - describe UI in a simple and clean format
  • Automatic generation - create ready Python code with Tkinter
  • Modular architecture - lexer, syntax analyzer, and code generator
  • Cross-platform - works on Windows, Linux and macOS
  • Debugging - built-in tools for diagnostics

Lui requires Python 3.6 or higher (Tkinter is usually included in the standard Python installation). Get started by cloning the repository from GitHub, creating a simple hello.lui file, and running python src/lui.py --file=hello.lui to generate your application.
